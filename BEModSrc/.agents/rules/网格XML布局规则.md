# 白易 Win32UI 网格 XML 布局规则

本规则依据当前 VS 设计器与 `WindowCppTranslator.cs` 的实际实现整理。涉及窗口 XML 中的网格布局时，以本文件为准，不要自行猜测属性名或格式。

## 1. 网格容器

任意实际窗口/容器组件节点，只要同时具有 `be_grid_row` 与 `be_grid_col`，就被视为启用了网格布局。

示例：

```xml
<窗口 be_version="1.0" be_rect="50,50,440,272"
      be_grid_row="30px-1-2-25px"
      be_grid_col="1-1-1"
      be_grid_padding="8,8,8,8"
      be_grid_gap="6,6">
  ...
</窗口>
```

规则：
- `be_grid_row` 与 `be_grid_col` 必须同时存在；缺少任意一个都不是完整网格定义，XML→C++ 翻译时会报错。
- `be_grid_row`：定义行轨道。
- `be_grid_col`：定义列轨道。
- 多个轨道使用减号 `-` 分隔。
- 固定像素轨道写成 `Npx`，例如 `30px`、`25px`；N 必须 >= 0。
- 比例轨道直接写正整数权重，例如 `1`、`2`、`3`。它表示剩余空间的相对权重，不是百分比。
- 例如 `30px-1-2-25px` 表示 4 个轨道：首尾固定 30、25 像素，中间两项在扣除固定尺寸、内边距和间距后，将剩余空间按 1:2 分配。
- 比例权重可以同比缩放，例如 `1-2` 与 `10-20` 等价。
- 比例值不接受 0、负数或非整数。旧格式 `1.0` 可被设计器归一化为 `1`，但新 XML 不应主动写小数比例。
- 不再使用 `be_grid_row_unit` / `be_grid_col_unit`；单位直接写在每个轨道值内。

## 2. 容器级间距

网格容器还可使用：

```xml
be_grid_padding="左,上,右,下"
be_grid_gap="行间距,列间距"
```

当前设计器默认值为：

```text
be_grid_padding="8,8,8,8"
be_grid_gap="6,6"
```

规则：
- `be_grid_padding` 必须是 4 项数值，顺序为左、上、右、下。
- `be_grid_gap` 必须是 2 项数值，顺序为行间距、列间距。
- 这两组值按像素/逻辑布局单位使用。
- 固定轨道、内边距与轨道间距先从容器可用空间中扣除，剩余空间再分给比例轨道。

## 3. 子组件入户

一个控件只有在其**逻辑父容器已经启用网格**，并且控件自身存在 `be_lay` 时，才算正式进入该父容器的网格布局。

示例：

```xml
<按钮 be_name="按钮1"
      be_rect="10,10,100,30"
      be_lay="0,1,1,2"
      be_halign="0"
      be_valign="0"
      be_margin="0,0,0,0"
      标题="按钮" />
```

### `be_lay`

格式：

```text
行,列,跨行,跨列
```

例如：

```text
0,0,1,1
```

表示第 1 行第 1 列，占 1 行 1 列。

```text
0,1,1,2
```

表示第 1 行第 2 列开始，占 1 行并横跨 2 列。

规则：
- 行、列索引从 0 开始。
- 第 3、4 项“跨行/跨列”必须大于 0。
- `be_lay` 缺失时，该控件不受父网格管理，仍按 `be_rect` 自由布局。
- 设计器中“游离粘贴但尚未正式落户”的控件，也不会因为父容器有网格就自动参与布局。

## 4. 对齐与外边距

网格子组件可使用：

```text
be_halign="0|1|2|3"
be_valign="0|1|2|3"
be_margin="左,上,右,下"
```

水平对齐：

```text
0 = 拉伸
1 = 居左
2 = 居中
3 = 居右
```

垂直对齐：

```text
0 = 拉伸
1 = 居顶
2 = 居中
3 = 居底
```

默认值：

```text
be_halign="0"
be_valign="0"
be_margin="0,0,0,0"
```

`be_margin` 必须是 4 项数值，顺序为左、上、右、下。

## 5. `be_rect` 与网格结果的关系

即使控件已经进入网格，也必须继续保留自己的 `be_rect`。

当前设计器约定：
- `be_rect` 始终保存控件原始/期望尺寸与自由布局位置。
- 网格计算结果只决定实际设计态/运行期布局位置与尺寸，不会反向污染 `be_rect`。
- 对于非拉伸的居中、居左、居右、居顶、居底控件，网格需要用 `be_rect` 中原始宽高作为其期望尺寸依据。

因此 AI 不得因为控件使用了 `be_lay` 就删除或伪造 `be_rect`。

## 6. 自动落位规则

设计器对仍处于默认：

```text
be_lay="0,0,1,1"
```

的网格直属子组件，可能按 XML 顺序自动填入空闲单元格，以避免多个控件全部重叠在左上角。

规则：
- 已显式设置非默认 `be_lay` 的控件优先占位，设计器不会自动改写它。
- 自动项只填补剩余空位。
- 网格容量不足时，多出的自动项保持原值，不强行迁移。
- AI 编写 XML 时如果明确知道布局位置，应直接写正确的 `be_lay`，不要依赖设计器自动分配。

## 7. 嵌套容器与子夹

网格可以嵌套。翻译器与设计器按父节点优先处理外层容器，再处理内层容器。

`<子夹>` 是无 `be_name` 的结构包装节点。网格查找“逻辑直属子组件”时会透明穿过这类包装节点，直到找到第一层真实组件。

例如：

```xml
<选择夹 be_name="选择夹1"
        be_rect="10,10,300,200"
        be_grid_row="1-1"
        be_grid_col="1-1">
  <子夹 标题="第一页">
    <按钮 be_name="按钮1"
          be_rect="10,10,80,30"
          be_lay="0,0,1,1" />
  </子夹>
  <子夹 标题="第二页">
    <按钮 be_name="按钮2"
          be_rect="10,10,80,30"
          be_lay="1,1,1,1" />
  </子夹>
</选择夹>
```

当前实现中，多夹组件的不同子夹拥有各自实际页 HWND。网格定义属于多夹容器，但设计器在计算几何时会按每个控件真实的父 HWND 分组，因此不同页中的控件仍分别相对各自页面布局。

注意：如果希望**每个子夹内部有不同的独立网格定义**，当前源码并没有把 `<子夹>` 本身当成真实网格容器；`子夹` 是透明结构节点。应使用页内的真实容器组件承载独立网格，而不要给 `<子夹>` 节点自行发明 `be_grid_*` 语义。

## 8. XML→C++ 的实际翻译结果

启用网格后，翻译器会在窗口的 `#pragma region 组件成员` 中为每个网格容器自动维护一个匿名 `网格布局` 成员：

```cpp
struct : 网格布局 {
}_网格_容器名;
```

根窗口使用：

```cpp
_网格_窗口
```

生成的 `载入()` 中大致执行：

```cpp
_网格_容器名.绑定(&容器名);
_网格_容器名.置内边距(...);
_网格_容器名.置间距(...);
_网格_容器名.设置行({ ... });
_网格_容器名.设置列({ ... });
_网格_容器名.放置(控件, 行, 列, 跨行, 跨列, 水平对齐, 垂直对齐, { 外边距... });
_网格_容器名.刷新布局();
```

AI 不应直接维护这些翻译产物；应修改 XML 后调用 `xml_to_design_cpp` 重新生成。

## 9. 推荐 XML 示例

```xml
<?xml version="1.0" encoding="utf-8"?>
<窗口 be_version="1.0"
      be_rect="50,50,500,320"
      be_grid_row="40px-1-40px"
      be_grid_col="120px-1"
      be_grid_padding="8,8,8,8"
      be_grid_gap="6,6"
      标题="网格示例">

  <标签 be_name="标签1"
        be_rect="0,0,80,30"
        be_lay="0,0,1,1"
        be_halign="0"
        be_valign="2"
        be_margin="0,0,0,0"
        标题="用户名" />

  <编辑框 be_name="编辑框1"
          be_rect="0,0,180,30"
          be_lay="0,1,1,1"
          be_halign="0"
          be_valign="2"
          be_margin="0,0,0,0" />

  <按钮 be_name="按钮1"
        be_rect="0,0,96,32"
        be_lay="2,1,1,1"
        be_halign="3"
        be_valign="2"
        be_margin="0,0,0,0"
        标题="确定" />
</窗口>
```

上例只演示网格专用属性；普通控件属性仍必须依据 `get_ui_control_metadata` 返回的 `META_控件名[]` 编写，不能凭空添加。
