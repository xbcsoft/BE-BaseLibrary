文本显示区

SciterUI 是一套基于 Sciter 引擎构建的轻量级桌面 GUI 框架。它将现代 Web 技术与原生 Windows 窗口能力相结合，支持玻璃态半透明背景、异形窗口、DirectComposition 硬件加速渲染等特性。

本框架使用 C++ 编写宿主程序，通过 Sciter 加载本地 HTML/CSS/JS 资源，实现界面与逻辑的解耦。前端采用纯 CSS 变量驱动的主题系统，可随系统明暗模式自动切换，无需重新加载页面。

窗口层面支持标准模式、异形裁剪模式与托盘驻留模式。标题栏、菜单栏均由 HTML 渲染，通过 postMessage 与 C++ 宿主双向通信，调用最大化、最小化、关闭、置顶等原生能力。

滚动条样式统一采用透明轨道加内嵌圆角灰色滑块的设计语言，悬停时滑块透明度提升以提供视觉反馈。该样式同时应用于页面主滚动区、文本域输入框以及本只读文本显示区，保持全局视觉一致性。

所有交互组件（按钮、输入框、下拉、开关、标签页、表格、时间线等）均内置明暗双主题适配，并通过 CSS 自定义属性实现细粒度颜色控制，便于二次定制与主题扩展。
